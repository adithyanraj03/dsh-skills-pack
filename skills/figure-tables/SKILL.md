# figure-tables

A figure edited by hand cannot be regenerated when results change. Every figure and table comes from a script and a data file.

## Steps

1. Find the existing pipeline: figure scripts, table generators (e.g. a `make_tex_assets.py` that writes `generated/table_*.tex` and `generated/numbers.tex`), and the results files they read. Use `graft_ask` / `graft_grep` if indexed. Extend that pipeline; do not start a parallel one.
2. Figures
   - Script reads the results file and writes the figure file. No numbers typed into the plot script.
   - Size the figure at its final printed width (single column ~3.5 in, double ~7 in) and set fonts so they print at no smaller than the body footnote size (about 8 pt). Do not shrink a large figure in LaTeX.
   - Vector output (PDF/SVG) for plots; PNG at >= 300 dpi only for images.
   - Color-blind-safe palette (e.g. Okabe-Ito or viridis family); also distinguish series by marker or line style so it survives grayscale.
   - Axis labels with units, legend that does not cover data, no chart titles that duplicate the caption.
3. Tables
   - Generated `.tex` from the results file, with a "generated by <script> -- do not edit" header.
   - `booktabs` (`\toprule`, `\midrule`, `\bottomrule`), no vertical rules, numbers right-aligned or aligned on the decimal (`siunitx` `S` columns if the paper uses it), consistent decimals per column, best result marked consistently (bold) and the marking explained in the caption.
   - Report spread (± std over seeds) where the claims depend on it.
4. Captions say what is shown and the takeaway in one sentence; every figure and table is referenced in the text.
5. Regenerate, rebuild (latex-build), and check the PDF page where each one appears.

## Stop when

- Each figure/table is produced by a script from a data file, the paper builds clean, and you have listed script, input and output for each.

## Rules

- Never edit generated tables or figure files by hand. Change the script or the data.
- Never change plotted or tabulated values to "look better". If a value looks wrong, report it (see claim-check).
